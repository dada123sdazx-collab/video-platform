ИНСТРУКЦИЯ ПО ДОБАВЛЕНИЮ ВИДЕОФАЙЛОВ
======================================

Положите сюда файлы с именами:
  video-1.mp4
  video-2.mp4
  video-3.mp4
  ...
  video-12.mp4

Эти имена соответствуют видео в базе данных (seedFirestore.js).

Требования к файлам:
- Формат: MP4 (H.264 + AAC) — лучшая поддержка браузерами
- Размер: рекомендуется до 50 МБ для быстрой загрузки
- Разрешение: 720p или 1080p

Где взять тестовые видео:
- https://www.pexels.com/videos/ (бесплатно, CC0)
- https://pixabay.com/videos/ (бесплатно, CC0)
- https://coverr.co/ (бесплатно)
- Свои короткие mp4-файлы

После добавления файлов запустите приложение:
  npm run dev
